Save with one tap

Each Shortcut run adds a new bookmark for the current track or podcast episode, playing or paused. It cannot read, rename, delete, or overwrite existing bookmarks, or control playback.

Shown once. Copy it now and keep it private.

  1. Add a URL action using .
  2. Add Get Contents of URL: method POST, headers Authorization = Bearer YOUR_CREDENTIAL and X-Shortcut-Response = notification, and empty JSON body.
  3. Get dictionary value message from the response and use Show Notification.
  4. Run once to allow network access, then add the Shortcut to your Home Screen or widget.

Keep Spotify tokens out of the Shortcut. Never share a Shortcut containing this credential.
